# Asset provenance

| Asset | Source / author | Permission |
|---|---|---|
| `tilesets/workspace.svg` | Project-authored geometric atlas, generated by `scripts/generate_office_assets.py` | MIT, `LICENSE.txt` |
| `maps/studio.tmj`, `maps/atrium.tmj` | Project-authored layouts from the same generator | MIT, `LICENSE.txt` |
| `scene/office/portraitArt.ts` | Project-authored pixel drawing implementation and fictional cast palettes | MIT, `LICENSE.txt` |
| `components/Icon.tsx` | Project-authored SVG stroke geometry | Project source; no external icon artwork |
| `fonts/press-start-2p-latin-400.woff2` | Cody Boisclair, [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) | SIL OFL 1.1, `fonts/LICENSE.txt` |
| `fonts/inter-latin-var.woff2` | The Inter Project Authors, [Inter](https://github.com/rsms/inter) | SIL OFL 1.1, `fonts/LICENSE.txt` |
| `fonts/jetbrains-mono-latin-var.woff2` | The JetBrains Mono Project Authors, [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | SIL OFL 1.1, `fonts/LICENSE.txt` |

Rebuild the atlas and maps with `python scripts/generate_office_assets.py`.
The SVG remains editable source. The current renderer uploads character buffers
with nearest-neighbor sampling; the portrait renderer paints pixels directly.
Project-authored dialogue is retained in `scene/office/cafeteriaLines.ts`.

Renderer replacement and source comparison are documented in
[`docs/UI_REPLACEMENT.md`](../../../docs/UI_REPLACEMENT.md).
Production builds include the artwork and font permissions in
`THIRD_PARTY_NOTICES.txt`. Earlier Git revisions contain their historical sources
and notices; this replacement does not rewrite Git history.
