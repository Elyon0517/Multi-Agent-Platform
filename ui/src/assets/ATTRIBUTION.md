Rebuild the vector atlas and maps with `python scripts/generate_office_assets.py`.
No purchased image pack is required. The original SVG is editable source,
rasterized by Pixi at 128×64 pixels with nearest-neighbor scaling.
Original dialogues are in `scene/office/cafeteriaLines.ts`.

Full retained code notices are in `ui/THIRD_PARTY_NOTICES.md`. The production
build emits `THIRD_PARTY_NOTICES.txt`, including code, artwork and font licenses.
Previously bundled restricted art is removed from the current source tree;
old Git commits require separate history cleanup before redistributing those commits.
